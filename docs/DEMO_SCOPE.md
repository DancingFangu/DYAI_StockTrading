# Demo Scope

## Must Have

- single-player game session
- 7 trading days
- 5 virtual stocks
- instant buy and sell
- player cash, positions, and total asset
- random daily event
- AI trader actions
- final rating

## Not In First Version

- real stock data
- real order book
- cancel order
- password login
- admin dashboard
- skill shop
- multiplayer
- voice and sound system
