# Game Rules

## Round

One round has 7 trading days.

Each trading day has a default timer, but the player can end the day early.

## Trading

Buy and sell orders execute immediately at the current stock price.

The system validates:

- enough cash before buying
- enough position before selling
- stock price cannot fall below 1

## AI Agents

AI agents act like normal traders. They can generate trading intent and chat text, but they cannot directly change player assets or bypass game rules.
