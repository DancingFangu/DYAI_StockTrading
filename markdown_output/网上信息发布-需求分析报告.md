           产品名称：股票交易系统——网上信息发布子系统
           大项目总称：证券股票交易系统
           本组负责子系统：网上信息发布子系统
           主要用户群：普通查询用户、VIP 查询用户
  2.2   项目背景
  随着金融科技的爆发式增长，现代投资者对股票交易数据的时效性、直观性以及跨系统联动性提出了极为严苛
  的要求。在软件工程基础课程的综合实验设计中，团队选择开发一套全功能的“证券股票交易系统”。
  其中，“网上信息发布子系统”作为大系统的前台 Web 服务窗口，承担着将中央交易引擎中高频变动的行情数
  据，以每5秒/次的频率稳定、安全、直观地传递给终端用户的重任。它是连接后端核心高频交易与前端散户决
  策的关键桥梁。
  2.3   项目目标
  本子系统的建设目标是搭建一个高并发、低延迟、多端适配、具备差异化权限控制的在线股票交易信息发布平
  台。
    1. 实现多维信息检索：提供股票代码、名称的精确和模糊双向互查，确保响应延迟在高峰期可控。
    2. 高保真图表渲染：构建日K、月K、年K多周期图表渲染引擎，支持高频（5秒/次）定时局部刷新重绘。
    3. 差异化服务隔离：支持普通账号注册及付费通道，隔离普通信息与 VIP 高级统计数据。


  2.4   项目用户
      1. 普通注册用户：主要进行基础的股票代码/名称互查、查看最新实时行情基础价格，可申请找回或修改密
         码。
      2. 付费高级/VIP用户：系统的高级贡献者，除基础功能外，还可解锁并深度浏览高频日/月/年 K 线走势图
         以及跨系统联动资产包。
      3. 外部系统接口/次要参与者：即中央交易系统接口（提供实时高频行情流） 。
      4. 系统管理员：系统的后端维护者，负责系统的安全日志审计、错密锁定解锁、高并发时期的性能监控以
         及基础股票静态信息的维护。
  三.需求说明
  3.1   整体需求
  本子系统旨在建立一个在线交易信息发布平台，通过对不同用户身份的认证，系统需提供差异化的交易数据和
  统计信息服务。核心目标是确保股票数据的实时性、准确性、可追溯性，并提供直观的图表分析工具，辅助用
  户进行投资决策。同时保证系统运行稳定可靠，满足日常及开盘高峰期使用需求。最后需要支持在大多数流行
  的 Web 浏览器中正确显示和执行，包括 Firefox、Chrome、Edge 等。
