# 《股票大亨》核心玩法 UI 设计（v2 · 卡牌识破 AI · 骗子酒馆风）

> 机制：**「读今日新闻事件 + 调查 6 个 AI 的公开发言，用信息卡挖隐藏信息，再用行动点下注，收盘骰子结算」**。
> 技术：**React 单页 demo + FastAPI / DeepSeek**（DeepSeek 只生成 AI 公开发言，不决定结算）。
> 美术：**整体走骗子酒馆（Liar's Bar）风格**——昏暗地下牌桌、暖吊灯、木纹皮革、烟雾感；AI 发言用 **Codex 通知气泡** 样式。
>
> 关系：本文档**取代** [祝福选择界面UI设计.md](祝福选择界面UI设计.md) 及早期"星露谷小镇"设想。[模拟宇宙扩展设计.md](模拟宇宙扩展设计.md) 的祝福/流派**本版不实现**，留作后续储备。

---

## 一、设计目标

让玩家**第一眼读懂操作顺序**：

```
① 读今日新闻事件（中部上方）＋ 看 6 个 AI 说话（左侧剧场）
② 选 2 张信息卡（右侧候选）→ 用卡调查 AI / 核对新闻
③ 推理：这事件利好/利空哪只股？谁在说真话？→ 用行动点下注（中部交易区）
④ 收盘骰子结算 → 复盘揭真相
```

整屏是一张**昏暗的地下牌桌**：你坐在桌前，对面 6 个像素对手，手里 2 张牌，桌上 5 只股票就是今天的注。**淡化股票软件感，强化牌桌博弈感。**

## 三、左侧 AI 剧场（AgentStage）

### 3.1 六个 Q 版圆润像素小人（AgentSprite）

- 竖排 6 个 **Q 版、圆润**的像素小人（codex pets / pethub 那种胖乎乎的可爱像素感），第一版用 **CSS 拼像素头像**实现，有 sprite 素材后替换。
- **不显示角色标签**（不写"价值投资者"等）。只露：名字、头像、昨日收益、当前排名。风格全靠发言+调查+复盘去猜。
- 像素渲染 `image-rendering: pixelated`，整数倍放大；烛光下打一道暖色描边光；待机 `idle-bob` 轻微上下浮动。
- **5 种状态**（必须可视区分）：

| 状态 | 视觉 | 触发 |
|------|------|------|
| `default` | 正常亮度，待机晃动 | 平时 |
| `speaking` | 高亮+前移2px+暖光描边，右侧弹气泡 | 轮到它说话 |
| `selectable` | 脉冲光圈+可点 | 玩家用卡后进入"选目标 AI" |
| `investigated` | 角标 ✔，气泡显示调查结果 | 该卡对它用过 |
| `locked` | 降饱和变暗+不可点 | 行动点0 / 非选目标阶段 |

### 3.2 发言气泡（SpeechBubble）— Codex 通知框样式

要求：**头像与气泡同一水平行，气泡从小人右侧伸出**。

```
┌──────┐   ┌──────────────────────────────────────┐
│ 🔮   │ ◀ │ 老K：「东海化工那破事别信,我反正            │
│ 老K  │   │       不碰它。」                         │
└──────┘   └──────────────────────────────────────┘
 头像格        发言泳道(锚定到当前说话小人那一行的Y)
```

- **泳道固定**：小人右侧划一条发言泳道（left:160px 起，宽 ~360px），气泡只在泳道内展开，**绝不越界**。
- **一次只一个小人说话**（`speakingAgentId`）：开盘"AI 发言阶段"六人**依次**冒泡，每人停留 ~3s，可"加速/跳过"；说话者 `speaking` 态，余者变暗。
- **气泡样式**（骗子酒馆质感）：圆角 8px、1px 暖铜描边 `#c9a86a`、半透明深木底 `rgba(30,22,16,.92)`、左侧朝小人的小三角嘴、文字打字机逐字显现（`steps()`）。
- **气泡复用**：行动阶段用卡调查某 AI 时，**调查结果显示在该 AI 气泡**；收盘复盘时切换为"真实行动揭示"。
- 实现：左栏 `position:relative`；气泡 `position:absolute; left:160px; top:<当前小人Y>`，切人改 `top`，气泡"长"到那一行旁边。

## 四、中部主区

### 4.1 今日新闻事件（NewsCard）— 本玩法的"题面"

**新闻不是标签，是一段事件叙事**，描述「谁 + 在哪 + 做了什么」，玩家要**自己推理**它影响哪只股、利好还是利空。

- 例：
  - *"东海化工董事长昨夜飞往深圳，与某 3D 打印龙头密谈耗材独家供货。"* → 玩家需判断：利好"东海化工"(科创01)？还是其竞争对手利空？
  - *"网传新能源车企 X 因电池起火被约谈，官方暂未回应。"* → 利空相关新能源股？还是只是谣言？
- **新闻不直接标注目标股 / 利好利空 / 真假**。这三件事正是玩家的推理任务：
  1. 事件 → **影响哪只股**（靠常识/行业关联推理）
  2. 利好还是利空（靠事件性质推理）
  3. **真还是假**（靠"对照新闻"卡，或交叉 AI 发言判断）
- 内部由本地规则持有 `target_stock` 与 `真利好/真利空/假新闻`，收盘才公布；DeepSeek 可用于把这条事件写得更生动，但真假与目标由本地规则锁定。
- 视觉：电报/旧报纸质感卡片，开盘阶段第一个聚光淡入，行动阶段常驻顶部。

### 4.2 股票交易区（5 只股票 + K 线）

- 紧凑表：`代码 │ 名称 │ 现价 │ 涨跌% │ 我的持仓`，涨红跌绿。
- **K 线保留**：每只股票行可展开 `▸ K线`，弹出该股 K 线小图（含基础均线），作为辅助判断依据；非主视觉但完整可用。
- 选中某股 → 快捷买卖按钮（替代手动输入股数）：

```
买入： [小仓 25%]  [半仓 50%]  [重仓 80%]      ← 按可用现金比例
卖出： [减仓 30%]  [半仓 50%]  [清仓 100%]     ← 按持仓比例
```
- **每次买/卖消耗 1 行动点**；现金不足禁用买入，无持仓禁用卖出。
- **现价实时跳动仅作视觉预演**，收盘以骰子结算为准（§6）。
- 底部 `[📋 查看今日复盘]`，收盘后亮起。

### 4.3 行动点条（ActionPointBar）

- 顶部状态条显示 `🎫 ●●●○○ 3/5`。每用一张卡 / 每笔交易 -1。
- 归零：禁用出牌与交易，只留 `[收盘结算]`。
- 点击消耗前给确认提示"将消耗 1🎫"，防误点浪费。

## 五、右侧候选卡区 与 底部手牌栏

### 5.1 候选卡区（CandidateCardArea）

- 每个交易日开始刷 **3 张候选卡**；玩家**选 2 张**为当日手牌（**选牌不消耗行动点**）。
- 选满 2 张 → 3 张候选**消失**，区域显示"今日手牌已确认"。未选作废，手牌当日收盘清空。
- 卡面（统一纸牌尺寸，皮革牌背）：

```
┌──────────────┐
│ 🔍      1🎫   │  ← 左上类型图标，右上行动点消耗
│   [像素图]    │
│   查仓        │  ← 卡名
│ 揭示目标AI    │
│ 昨日持仓方向  │  ← 短效果说明
└──────────────┘
```

### 5.2 底部手牌栏（HandDock）

- `position:fixed` 固定视口底部，全宽，高 ~150px，存 **2 张手牌**横排。
- **点卡 → 使用**：左侧 6 小人变 `selectable` → 点一个 AI → 扣 1🎫 → 该 AI 气泡显示调查结果。
- 已用卡**变灰**不可再用；**行动点不足整排禁用**。右侧附"状态日志"折叠条（今日操作流水）。

### 5.3 五张信息卡（第一版，只揭示信息）

| 卡 | 图标 | 效果（不改股价/现金/AI行为） |
|----|------|------------------------------|
| 查仓 | 🔍 | 揭示目标 AI 昨日的目标股票与方向 |
| 识别语气 | 🎭 | 揭示目标 AI 的发言模式（真心/虚张/反向喊话…） |
| 追问 | 💬 | 让目标 AI 追加一句更接近真相的发言 |
| 看资金流 | 💸 | 揭示目标 AI 当日真实下注强度（低/中/高） |
| 对照新闻 | 📰 | 揭示今日新闻**真假**（目标改为高亮新闻卡，而非 6 小人） |

## 六、每日阶段状态机（phase 驱动）

`GamePhase: 开盘新闻 → AI发言 → 选牌 → 行动 → 收盘结算 → 下一日`

| phase | 中部 | 左侧 AI | 右侧候选 | 底部手牌 | 可操作 |
|-------|------|---------|---------|---------|--------|
| `news` | 新闻事件聚光淡入 | 待机变暗 | 隐藏 | 空 | [继续] |
| `speech` | 新闻常驻 | 六人**依次**冒泡 | 隐藏 | 空 | [加速/跳过] |
| `pick` | 新闻常驻 | 待机 | **3 张亮起,选 2** | 空→填入 | 选 2 张 |
| `action` | 交易区激活 | 可被卡选为目标 | "已确认" | 2 张可用 | 用卡/买/卖(耗AP) |
| `settle` | 骰子结算动画 | 气泡切"真实行动" | 隐藏 | 清空 | [查看复盘] |
| `next` | 过场 | 重置 | 重刷 3 张 | 重置 | — |

> 门槛：未选满 2 张不能进 `action`；`action` 行动点为 0 只能进 `settle`。

## 七、收盘骰子结算（settle）

中部播放结算动画，每股一行骰子：

```
东海化工  基础3骰 +新闻(真利好+1) +AI净行动(+1) = 5 骰
          🎲4 🎲6 🎲2 🎲5 🎲3   成功(4/5/6)=3 → +4%
```

- 骰数 = 基础3 + 新闻修正(真利好+1/真利空-1/假0) + 当日 AI 真实行动净值（低中买+1/高买+2/低中卖-1/高卖-2/观望0），**钳制 1–6**。
- 成功数→涨跌：`0=-6% │ 1=-3% │ 2=+1% │ 3=+4% │ 4+=+8%`。
- 实时预演价与骰子冲突时，**以骰子为准**（覆盖收盘价）。

## 八、复盘界面（ReviewSummary）

收盘后点 `[查看今日复盘]`，全屏弹出，**必须展示**：

- 今日新闻事件**真假 + 真正影响的股票与方向**揭晓（对照玩家当初的推理）。
- 每个 AI：公开发言 ｜ 真实目标股+方向 ｜ 真实强度 ｜ 发言模式。
- 每只股票骰子结果与涨跌。
- 玩家今日操作 + 今日盈亏。
- **识破标记**：用对应卡查到隐藏信息 → 标"✔ 识破"，计 `识破 AI 次数`；被假发言/假新闻带偏 → 计 `被误导次数`。

布局：左列 6 个 AI 真相卡，右列新闻真相 + 股票骰子结算 + 玩家盈亏小结。

## 九、七日最终结算

展示：最终现金、持仓市值、总资产、收益率、玩家排名、击败 AI 数、识破次数、被误导次数、最佳交易日、最大失误。**（不设称号体系。）**

AI 也有虚拟资产曲线参与排名（第一版按其真实行动自动买卖结算）。

## 十一、视觉系统（骗子酒馆）

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg` | `#1a130d` | 暗木底 |
| `--wood` | `#2b1f14` | 面板/桌面 |
| `--leather` | `#3a2a1c` | 卡牌/手牌坞底 |
| `--felt` | `#1e3a2f` | 牌桌绿绒（候选/交易区底） |
| `--candle` | `#e8b563` | 暖吊灯光/聚光高亮 |
| `--brass` | `#c9a86a` | 描边/分割线 |
| `--text` | `#e8dcc8` | 暖白正文 |
| `--dim` | `#8a7a64` | 辅助/禁用 |
| `--up` | `#d9534f` | 涨(红) |

## 十二、响应式

- **桌面 ≥1280px**：左 220 / 中自适应 / 右 300 / 底固定 150。
- **窄屏 1024~1280**：左栏 220 + 泳道挤压中部 → 发言气泡改为**悬浮半透明层**盖在中部上方，不挤横向空间。
- **移动**：6 小人改**顶部横向滚动条**，点头像才弹气泡；候选卡与手牌**上下堆叠**，手牌坞可上拉抽屉；主内容留底 padding，禁止文本重叠。明确为简化版，完整体验在桌面。

## 十三、实现注意 / 风险

1. **AI 依次发言耗时**：6×3s=18s 纯等待会闷，给"一键加速/跳过"，允许气泡叠现而非严格串行。
2. **DeepSeek 延迟与降级**：发言走网络，必须本地备用台词库兜底（未配置 key/超时都回退），UI 不能卡 loading。
3. **行动点经济很紧**：5 点要覆盖"2 卡 + 几笔交易"。每点消耗前明确确认，避免误点。
4. **实时价 vs 骰子结算认知冲突**：复盘显式写"日内为预演，收盘以骰子为准"，否则被当 bug。
5. **新闻推理难度**：事件→股票的关联要让玩家"想得到"。5 只股票的行业/关系需在游戏内有迹可循（如开局给一份"市场名册"说明 5 家公司是干啥的），否则推理变瞎猜。
6. **手牌坞固定遮挡**：所有滚动主区加 `padding-bottom:150px`，移动端测试按钮不被遮。
