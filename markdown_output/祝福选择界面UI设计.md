# 股票大亨 — 交易日祝福界面 UI 设计

> 本文档专门描述 **「交易日祝福选择 / 事件主舞台」** 这一块界面（即模拟宇宙玩法的核心交互屏）。
> 它**不是**完整的交易所/K线界面，而是 [模拟宇宙扩展设计.md](模拟宇宙扩展设计.md) 中"盘前选祝福、盘中遇事件"的视觉落地方案。
> 审美参考：**骗子酒馆（Liar's Bar）**——昏暗、暖光、木质、牌桌、角色围坐的"地下交易所"氛围。

---

## 〇、先说批判（重要）

你给的三个想法我大体认同，但有几处会在实现时出问题，先摆出来，免得做到一半返工：

### 批判 1：六个小人竖排在最左 + 发言框水平展开，会撞到中间的卡片区

- 屏幕宽度有限（常见 1920px）。六个小人竖排占据最左 ~160px，而**发言框向右水平展开**至少需要 300~400px。
- 你的卡片刷新区在"中间靠右"，发言框一旦展开就会**盖住或挤压卡片**。
- **建议**：给发言框划一条固定的"发言泳道"（左侧 160px 小人 + 紧贴右侧 380px 发言区），卡片区从屏幕中线**之后**才开始。并且**同一时刻只允许一个小人发言**（其余小人变暗待机），避免六个框同时炸开。详见 [§3.1](#31-左侧栏六流派像素小人--发言系统)。

### 批判 2：主题冲突——之前定的是"星露谷·金融小镇"navy+金色，现在又要"骗子酒馆"暗酒馆风

- 这是两套完全不同的情绪：小镇是明亮治愈，酒馆是昏暗博弈。两者直接混在一起会很割裂。
- **建议**：把它们**分区而非混合**。整个 App 主壳（仪表盘/交易所）保持原 navy+金现代风；**唯独"交易日祝福界面"是一个独立的'地下交易酒馆'场景**——玩家点"开始今日交易"时，画面切到酒馆。叙事上解释为"散户们收盘后聚在地下酒馆密谋明日操作"。这样两套审美各得其所，过场还增加仪式感。本文档以酒馆风为准。

### 批判 3：这屏和"真正交易"的关系没说清

- 祝福界面是盘前/盘中的"仪式"，但**底部卡牌存放区应该贯穿整个交易日**（包括你后续看K线下单的时候），作为常驻 HUD。
- **建议**：底部卡槽是**全程常驻**的；切到交易所界面时，酒馆背景淡出，但底部卡槽仍在。卡牌即"你今天带着哪些 buff 上桌"。

### 批判 4："AI 发言"含义模糊 + 成本

- 如果六个小人每句话都走 LLM 实时生成，**延迟和费用都不可控**，而且容易胡说影响数值。
- **建议**：默认走**预写台词库**（每个流派几十条，按情境随机），仅在特定节点（如点评你刚做的一笔骚操作）才可选地调一次 LLM 生成花絮。把 LLM 当调味料，不当主菜。

### 批判 5：底部卡槽会被塞爆

- 按扩展设计，一天最多能收 ~12 张祝福。横排平铺会溢出。
- **建议**：底部按**流派分组堆叠**（六叠，每叠是该流派的祝福叠在一起，显示数字角标），点击某叠展开横向滚动查看。详见 [§3.3](#33-底部卡牌存放区常驻-hud)。

### 3.1 左侧栏：六流派像素小人 ＋ 发言系统

**这是你最在意的部分，重点设计。**

#### 形象
- 六个像素风小人，分别代表六大流派，是玩家的"军师/酒友"。
- 形象可从开源像素角色/宠物素材库取材（你提到的 codex pethub 之类），每个流派一只有辨识度的吉祥物，建议方向：

| 流派 | 小人设定建议 | 主色 |
|------|------------|------|
| 🛡️ 稳健防守流 | 戴钢盔/抱盾的老兵，沉稳 | 钢蓝 `#5b8db8` |
| ⚔️ 激进进攻流 | 叼雪茄/卷袖子的莽汉，跃跃欲试 | 血红 `#c0392b` |
| 🔮 信息先知流 | 戴墨镜的情报贩子，神秘 | 紫罗兰 `#8e44ad` |
| 🏄 趋势跟随流 | 戴鸭舌帽的冲浪客，轻快 | 翠绿 `#27ae60` |
| 🎲 事件驱动流 | 小丑/赌徒，咧嘴坏笑 | 橙金 `#e67e22` |
| 🤖 量化算法流 | 像素机器人，冷淡 | 银灰 `#95a5a6` |

#### 排布
- 竖排在最左，固定宽度 **160px**。每个小人占 **~150px 高**（含名字牌），六个正好铺满中段。
- 像素渲染：`image-rendering: pixelated`，做 2~3 倍整数放大，保持锐利不糊。
- 待机有轻微"呼吸/晃动"动画（`@keyframes idle-bob`），烛光下投一道暖色描边光。

#### 发言系统（核心交互）
你要的效果是"像 codex 的提醒消息框，但框子和 AI 小人**水平同行**"。落地规则：

```
┌──────┐   ┌─────────────────────────────────────┐
│ ⚔️   │ ◀ │ 激进军师：「怂什么？满仓干它！           │
│ 莽哥 │   │            今天是贪婪日，不梭哈对不起     │
│      │   │            这行情。」                    │
└──────┘   └─────────────────────────────────────┘
  160px              发言泳道 ~380px（紧贴小人右侧，同一水平行）
```

- **泳道固定**：小人右侧划一条 380px 宽的"发言泳道"，发言框只在此泳道内展开，**永不越界到卡片区**。
- **一次只一个**：同一时刻只有一个小人说话；说话的小人**高亮+前移2px**，其余五个**降饱和度变暗**（`filter: grayscale(.6) opacity(.5)`）。
- **框体样式**（致敬 codex 通知框）：
  - 圆角 8px、1px 暖色描边（`#c9a86a`）、半透明深木色底（`rgba(30,22,16,.92)`）。
  - 左侧一个朝向小人的小三角"嘴"，强调"这话是它说的"。
  - 文字打字机逐字显现（`steps()` 动画），短句即可，3~5 秒后自动淡出。
- **触发时机**：开盘掷骰后、刷新卡片后、你选了某张牌后、触发事件后、你做了一笔"骚操作"后。每个流派按情境从台词库随机取句（见 [§5](#五发言台词系统)）。
- **可点**：点小人 → 弹出该流派简介 + 它"推荐你拿的牌"（轻引导，不强制）。

> 实现注意：六个小人 + 泳道整体是一个 `position: relative` 的左栏；发言框 `position: absolute` 锚定到当前说话小人的垂直位置，`top` 跟随。这样无论谁说话，框都"长"在它旁边那一行。

### 3.2 中间靠右：三张刷新卡片区

- **位置**：屏幕中线偏右，留出和左侧发言泳道的安全距离。
- **三张祝福卡并排**，是每个交易日（及盘中节点）刷新出来的待选项。
- **卡面**（骗子酒馆扑克牌质感）：
  ```
  ┌──────────────┐
  │ 🛡️      ⭐    │  ← 左上流派图标，右上星级
  │              │
  │   [像素插画]  │  ← 中央祝福主题小图
  │              │
  │   小额止损    │  ← 卡名（做旧衬线/像素字）
  │ 单笔亏损-3%   │  ← 一句话效果
  │              │
  │ 已有🛡️×2     │  ← 角标：你已有几张同流派（提示回响进度）
  │   [ 选择 ]    │
  └──────────────┘
  ```
  - 牌有厚度感（多层 box-shadow 模拟卡牌叠影）、轻微 3D 倾斜随鼠标移动（`transform: rotateX/Y`）。
  - 稀有度发光：1星无光、2星暖金边、3星紫边+缓慢扫光（`shimmer`）。
  - Hover：牌微微抬起+发光，背面或下方滑出完整效果描述。
- **刷新按钮**：卡片下方居中。`🔄 刷新 (¥500)`，次数 `3/3` 递减；费用按 [扩展设计 §8.2](模拟宇宙扩展设计.md) 递增（500→1500→5000）。刷新时三张牌做"洗牌翻面→重发"动画。
- **选择 → 消失**：你点某张牌的 `[选择]`，**被选中的牌飞向底部卡槽**（飞行+缩小动画），**另外两张原地烧毁/碎裂淡出**（骗子酒馆式"弃牌"——可做火焰/灰烬粒子）。三张全部清空，舞台回到等待下一个节点。
- 你说的"晚间选择完卡片后三张卡片消失"——即此逻辑：**选定即清场**。

### 3.3 底部卡牌存放区（常驻 HUD）

- **全程常驻**（贯穿祝福屏和后续交易屏）。这是"你今天上桌带着的牌"。
- **按流派分六叠**，而不是平铺（避免塞爆）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  🛡️         ⚔️         🔮      🏄    🎲    🤖             │
  │ ┌▣┐        ┌▣┐        ┌▣┐    ─     ─     ─              │
  │ │▣│×2      │▣│×2      │ │×1                              │
  │ └─┘        └─┘        └─┘                                │
  │            🔥 回响·初现：稳健流 已就绪 [激活]   ⚗ 方程：未触发 │
  └─────────────────────────────────────────────────────────┘
  ```
  - 每叠是该流派祝福"叠在一起"的牌，右上角数字角标。
  - 点某叠 → 横向展开该流派全部祝福明细（可滚动）。
  - **回响进度**：当某叠达到 3/6/10 张，该叠亮起脉冲光，旁边出现 `[激活回响]` 按钮（见 [扩展设计 §5](模拟宇宙扩展设计.md)）。
  - **方程提示**：当满足双流派条件，底部中央亮起 `⚗ 方程：内幕交易 可触发`。

### 3.4 ④ 中央主舞台

- 大面积留白 + 烟雾/烛光氛围，是"叙事舞台"。
- 平时空着（只有氛围光）；当**触发事件**时，中央升起事件卡/对话框（全屏偏暗，聚光打在事件文本上），事件选项以"按钮牌"形式出现（见 [扩展设计 §13.5](模拟宇宙扩展设计.md)）。
- 旁白文字（如"开盘掷骰：贪婪日"）也在此淡入淡出。

### 3.5 ① 顶部状态条

`Lv.8 王牌交易员 │ 💰¥98,500 │ 💎积分 0 │ 🎲今日情绪：🤑贪婪 │ ⏱阶段：盘前 │ ⚙`

- 简短一行。情绪骰子结果常驻显示（影响玩家决策）。
- 阶段指示（盘前→早盘→午间→…→结算）用小进度点。

### 4.2 材质与光

- **背景**：暗木墙 + 中央一盏吊灯，`radial-gradient` 暖光打在牌桌，四周渐暗（vignette）。
- **烛光摇曳**：吊灯光晕做极缓慢的明暗+位移（`@keyframes candle-flicker`，4~6s 循环），制造呼吸感。
- **烟雾**：一层极低透明度的噪点/烟雾贴图缓慢飘动（`opacity .05~.1`），增加"地下"感。
- **木纹/皮革**：面板用做旧纹理（可用 CSS `repeating-linear-gradient` 模拟，或一张 tile 贴图）。

### 4.3 字体

- 卡名/标题：做旧衬线或像素衬线（营造"老酒馆招牌"感）。
- 正文：暖白无衬线（保证中文可读）。
- 数字（资金/积分）：等宽，带黄铜质感。
- 像素字（Zpix）仅用于角标、星级、小人名牌。

### 4.4 关键动效

| 动效 | 触发 | 描述 |
|------|------|------|
| `idle-bob` | 常驻 | 六小人轻微上下浮动 |

| `speaker-focus` | 发言 | 说话小人高亮前移，余者变暗 |
| `card-deal` | 刷新 | 三张牌洗牌→翻面发出 |
| `card-pick-fly` | 选牌 | 选中牌飞向底部卡槽 |
| `card-burn` | 弃牌 | 未选的两张烧成灰烬 |
| `candle-flicker` | 常驻 | 吊灯烛光摇曳 |
| `resonance-pulse` | 回响就绪 | 底部对应流派叠脉冲发光 |
| `dice-roll` | 开盘 | 情绪骰子翻滚定格 |

## 五、发言台词系统

### 5.1 数据结构（建议）

每个流派一个台词库，按情境分类：

```jsonc
{
  "aggressive": {            // ⚔️ 激进流·莽哥
    "name": "莽哥",
    "on_market_greedy":  ["怂什么？满仓干它！", "贪婪日不梭哈，对不起这行情。"],
    "on_market_panic":   ["越跌越买，这才是男人。", "别人恐惧我贪婪，懂？"],
    "on_pick_my_card":   ["这就对了，跟着我有肉吃。"],
    "on_pick_other":     ["啧，胆子这么小？"],
    "on_player_big_win": ["漂亮！这波干得漂亮！"],
    "on_player_big_loss":["亏了？加倍下注捞回来！"]
  },
  "defensive": { "name": "盾叔", /* ... */ },
  // ……六个流派
}
```

### 5.2 选句逻辑

- 监听游戏事件（掷骰、刷新、选牌、盈亏、事件）→ 映射到情境 key → 从对应流派台词库随机取一句。
- **谁说话**：默认由"与当前情境最相关的流派"开口（如贪婪日→激进流；暴跌→稳健流或事件流）。偶尔随机一个吐槽，增加生气。
- **冷却**：每个小人发言后 ≥8 秒不重复开口，避免刷屏。
- **可选 LLM**：仅在"点评玩家具体某笔交易"时，允许调一次 LLM 生成花絮（带超时降级到预写库）。

## 六、一个交易日的交互流程（串起来）

```
1. 玩家在仪表盘点「开始今日交易」
   → 画面切到地下酒馆（换肤过场，~0.6s）

2. 开盘掷骰
   → 中央骰子翻滚 → 定格「🤑 贪婪日」
   → 激进军师抢先发言：「贪婪日，梭哈！」

3. 盘前发牌
   → 中间靠右发出三张祝福卡（card-deal 动画）
   → 玩家可：选一张 / 刷新(¥500) / 看小人推荐
   → 选中：牌飞入底部卡槽，另两张烧毁

4. 进入早盘交易
   → 酒馆背景淡出，切到交易所K线界面
   → 但底部卡槽常驻（带着 buff 上桌）

5. 盘中触发事件（如科技板块异动）
   → 短暂切回酒馆/中央升起事件卡
   → 三选一，结算奖励（可能再得一张祝福 → 入卡槽）

6. 午间休市
   → 回酒馆，额外发一轮三张牌 + 可进祝福商店

7. 收集够同流派 → 底部回响就绪 → 玩家择机[激活]

8. 收盘结算
   → 当日盈亏、经验、成就、积分结算
   → 卡槽清空（祝福日末重置），经验/成就永久保留
   → 六小人按今日表现各说一句收场白
```

## 八、技术实现要点

- **换肤**：酒馆场景作为独立的 `<section class="tavern-scene">`，整套酒馆 CSS 变量挂在该作用域，不污染主壳。
- **像素小人**：用 sprite sheet（一张图含待机几帧）+ CSS `steps()` 帧动画，或单张 PNG + `image-rendering: pixelated` 放大。来源可取开源像素角色库（如你提到的 pethub 类素材），六个需统一画风。
- **发言框锚定**：左栏 `position: relative`，发言框 `position: absolute; left: 160px; top: <当前小人Y>`，JS 切换 `top` 即可"长"到说话者旁边。
- **卡片 3D 倾斜**：`transform: perspective(800px) rotateX() rotateY()`，跟随 `mousemove`。
- **弃牌烧毁**：CSS `@keyframes burn`（mask + 渐变位移）或少量 canvas 粒子。
- **氛围层**：吊灯光 `radial-gradient`、暗角 `box-shadow inset`、烟雾 `background-image` 缓动，全用 CSS，零依赖。
