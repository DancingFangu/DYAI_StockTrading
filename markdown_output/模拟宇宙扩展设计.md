## 一、核心设计理念

### 1.1 模拟宇宙精髓 → 股票交易映射

| 模拟宇宙 | 股票大亨 |
|----------|---------|
| 一次模拟宇宙探索 | **一个交易日** |
| 祝福 (Blessing) | **当日增益效果**，盘前选择，盘后清零 |
| 流派/命途 (Path) | **投资风格**，如稳健流、激进流、科技流等 |
| 宇宙碎片 (Cosmic Fragments) | **交易积分**，通过盈利赚取，用于刷新/购买 |
| 奇物 (Curio) | **特殊道具**，一次性或持续效果 |
| 事件/遭遇 (Occurrence) | **盘中随机事件**，满足条件可获额外祝福 |
| 回响 (Resonance) | **流派终极技能**，收集足够同流派祝福解锁 |
| 区域选择 (Domain) | **交易时段选择**，玩家选下一个"房间"类型 |
| 方程 (Equation) | **双流派协同效果**，跨流派组合触发 |

### 1.2 核心博弈循环

```
盘前选祝福（3选1，可刷新）
    ↓
选择下一个"房间" → 遇到事件/交易/休息
    ↓
交易盈利 → 赚取交易积分
    ↓
使用积分刷新祝福 / 购买奇物 / 激活能力
    ↓
积累同流派祝福 → 解锁回响
    ↓
收盘结算 → 祝福清零，经验和成就永久保留
```

### 1.3 "赌"的设计点

1. **祝福三选一**：每次只给3个随机祝福，可能都不理想 → 赌刷新 or 凑合选
2. **刷新代价递增**：第一次¥500，第二次¥1500，第三次¥5000 → 赌值不值
3. **事件分岔**：每个事件有2-3个选项，结果有好有坏 → 赌判断力
4. **流派回响门槛**：凑不够同流派祝福就触发不了 → 赌流派纯度 vs 灵活混搭
5. **奇物副作用**：强力的奇物往往有负面效果 → 赌承受能力
6. **精英房间**：高风险高回报的交易机会 → 赌胆量

## 三、祝福稀有度与池

### 3.1 稀有度分布

| 稀有度 | 出现权重 | 数量 | 特点 |
|--------|---------|------|------|
| ⭐ 1星 | 60% | 每流派4个 | 小幅度稳定增益 |
| ⭐⭐ 2星 | 30% | 每流派4个 | 中等增益，有条件触发 |
| ⭐⭐⭐ 3星 | 10% | 每流派3个 | 强力效果，改变玩法 |

### 3.2 选择时的权重机制

每次给玩家展示3个祝福时：
- 60%概率：2个1星+1个2星
- 25%概率：1个1星+1个2星+1个3星
- 10%概率：2个1星+1个3星
- 5%概率：3个2星（欧皇时刻）

### 3.3 流派偏向

玩家已有的祝福会影响后续随机：
- 已拥有≥3个同流派祝福 → 该流派出现概率+20%
- 已拥有≥5个同流派祝福 → 该流派出现概率+35%（帮助触发回响）
- 拥有0个某流派 → 该流派首次出现概率+15%（鼓励尝试）

## 四、交易日结构：房间地图系统

### 4.1 一日六个阶段

```
┌────────────────────────────────────────────────────┐
│ 阶段1: 盘前准备 (Pre-market)                        │
│ ├─ 查看今日市场情绪                                  │
│ ├─ 选择初始祝福（3选1，可刷新最多3次）                  │
│ └─ 预览今日可能触发的特殊事件                         │
├────────────────────────────────────────────────────┤
│ 阶段2: 早盘交易 (Morning Session)  09:30-11:30       │
│ ├─ 正常交易                                          │
│ ├─ 随机事件可能触发                                   │
│ └─ 盈利赚取交易积分                                   │
├────────────────────────────────────────────────────┤
│ 阶段3: 午间休市 (Midday Break)    11:30-13:00        │
│ ├─ 选择下一个"房间"类型（见4.2）                      │
│ ├─ 获得一次额外的祝福选择机会（3选1）                   │
│ └─ 可进入"商店"购买奇物                               │
├────────────────────────────────────────────────────┤
│ 阶段4: 午盘交易 (Afternoon Session) 13:00-14:30      │
│ ├─ 根据选择的房间类型有不同效果                        │
│ └─ 可能是精英挑战或特殊事件                            │
├────────────────────────────────────────────────────┤
│ 阶段5: 尾盘冲刺 (Closing Rush)     14:30-15:00       │
│ ├─ 选择最后一个房间                                  │
│ ├─ 尾盘30分钟"暴击时刻"（激进流3星祝福激活）           │
│ └─ 最终交易机会                                      │
├────────────────────────────────────────────────────┤
│ 阶段6: 盘后结算 (Settlement)      15:00后            │
│ ├─ 当日盈亏核算                                      │
│ ├─ 经验值计算                                        │
│ ├─ 成就检测                                          │
│ └─ 祝福清零，为明天做准备                             │
└────────────────────────────────────────────────────┘
```

### 4.2 房间类型选择

在每个阶段转换时（午间休市和尾盘前），玩家需要选择下一个"房间"类型：

```
┌──────────┬──────────┬──────────┬──────────┐
│ 📈       │ 🎲       │ 🛒       │ ☕       │
│ 普通交易  │ 随机事件  │ 祝福商店  │ 休整恢复  │
│          │          │          │          │
│ 低风险   │ 未知风险  │ 消耗积分  │ 无风险    │
│ 稳定收益  │ 可能大奖  │ 购买祝福  │ 轻微恢复  │
│ 小概率掉  │ 也可能   │ 或奇物    │ 清除负面  │
│ 落祝福   │ 倒霉     │          │ 效果      │
└──────────┴──────────┴──────────┴──────────┘

┌──────────┐
│ ⚡       │
│ 精英挑战  │
│          │
│ 高风险   │
│ 高回报   │
│ 失败惩罚  │
│ 成功大奖  │
└──────────┘
```

**各房间详解：**

| 房间类型 | 效果 | 风险 | 收益 |
|---------|------|------|------|
| 📈 **普通交易** | 标准交易时段，一切正常 | 常规市场风险 | 常规收益，10%概率掉落随机1星祝福 |
| 🎲 **随机事件** | 必定触发一个盘中事件（见第七节） | 事件可能有负面影响 | 事件奖励，满足条件可获额外祝福 |
| 🛒 **祝福商店** | 可以花费交易积分购买祝福（3选1）或奇物 | 消耗积分，可能买不起 | 定向获取想要的祝福 |
| ☕ **休整恢复** | 清除一个负面效果，恢复部分被冻结资金 | 机会成本（放弃其他选择） | 安全，稳健推进 |
| ⚡ **精英挑战** | 高风险交易任务（如"30分钟内盈利5%"） | 失败有惩罚（扣积分/锁资金） | 成功给2星+祝福或传说级奇物 |

### 4.3 房间地图的可视化（UI参考）

## 七、事件系统

### 7.1 事件触发机制

- **被动触发**：交易过程中每10分钟检查一次（与现有系统一致）
- **主动选择**：选择"随机事件"房间时必定触发
- **条件触发**：满足特定条件时触发专属事件（如"科技股仓位>60%"）

### 7.2 事件结构

每个事件遵循标准结构：
```
事件触发 → 展示事件描述（剧情文本）
         → 提供2-3个选项
         → 每个选项有不同结果
         → 可能获得：祝福/奇物/交易积分/正面效果
         → 可能承受：负面效果/资金损失/积分扣除
```

### 7.3 事件分类与示例

#### A. 市场异动事件

**事件：科技板块异动**
```

选项1：【重仓杀入】立即买入相关科技股（至少30%仓位）
  → 成功：获得"信息先知流"1个随机祝福 + 当日该板块涨幅加成+3%
  → 条件检测：若买入后该股上涨>5%，额外获得一个2星科技相关祝福

选项2：【轻仓试探】小额买入观察
  → 获得交易积分+200
  → 条件检测：若当日科技股总交易量>500手，额外获得1星祝福

选项3：【按兵不动】不参与
  → 获得"稳健防守流"1星祝福
  → 无风险无额外收益
```

**事件：熔断预警**

## 八、刷新与交易积分

### 8.1 交易积分（宇宙碎片）

**赚取方式：**
| 行为 | 获得积分 |
|------|---------|
| 每笔盈利交易 | +（盈利额/100）积分 |
| 完成每日挑战 | +100~300积分（根据难度） |
| 解锁成就 | +50~200积分（根据品质） |
| 事件奖励 | 不定 |
| 精英挑战成功 | +500积分 |

**消耗方式：**
| 行为 | 消耗积分 |
|------|---------|
| 刷新祝福选择（盘前） | ¥（现金，见8.2） |
| 祝福商店购买祝福 | 200~800积分 |
| 祝福商店购买奇物 | 500~1500积分 |
| 激活额外祝福选择机会 | 300积分/次 |

### 8.2 祝福刷新机制（盘前+盘中的3选1）

```
首次获得3个祝福 → 免费

第1次刷新 → 消耗 ¥500
第2次刷新 → 消耗 ¥1,500
第3次刷新 → 消耗 ¥5,000
```

- 每次刷新替换全部3个选项
- **不会**出现与上一轮完全相同的祝福
- 第3次刷新后不能再刷（当日最多3次）
- 盘前和盘中共享刷新次数上限

### 8.3 积分的"赌"设计

积分系统是关键的博弈点：
- 积分可以用来买祝福/奇物 → 增加收益能力
- 但积分的来源是盈利 → 需要先冒险交易
- 花积分买祝福 → 可能更赚，也可能买了没用的祝福
- 不花积分 → 积分盘后清零，浪费了
- **核心矛盾**：保守赚积分买祝福 vs 激进赚钱买更好的祝福

## 十、博弈系统：骰子与市场情绪

### 10.1 每日市场情绪骰子

参考模拟宇宙的"骰子"机制。每天开盘前，系统掷一个"市场情绪骰子"，决定今日整体基调：

| 骰面 | 情绪 | 效果 |
|------|------|------|
| 1-2 | 😰 恐慌 | 全市场下跌压力大，但事件触发率+50% |
| 3-4 | 😐 平淡 | 正常市场，无特殊波动 |
| 5-6 | 🤑 贪婪 | 全市场上涨动力强，但泡沫风险（可能出现突然反转） |
| 🎲 | 🌈 混沌 | 每个交易时段切换一次情绪（不可预测） |

玩家在盘前可以看到情绪骰子的结果，据此调整流派选择。例如：
- 恐慌日 → 更倾向于选稳健流/事件流
- 贪婪日 → 更倾向于选激进流/趋势流
- 混沌日 → 量化流的稳定性更有价值

### 10.2 可选：自定义骰面

玩家可以在"祝福商店"或特殊事件中获得**"骰子操纵权"**：
- 重掷市场情绪骰子（1次/日，消耗¥3000或500积分）
- 锁定骰面（防止反转事件改变情绪）

## 总结

本扩展设计为股票大亨注入了模拟宇宙式的Roguelike博弈体验。核心要点：

1. **每个交易日=一次模拟宇宙**：祝福、奇物、事件、回响在日末清零，每日都是新挑战
2. **六种投资流派**：覆盖从保守到激进、从直觉到量化的各种风格
3. **选择的博弈**：祝福3选1、事件分岔、刷新代价递增 → 处处是赌博式的trade-off
4. **流派回响**：收集同流派祝福解锁终极技能，鼓励策略深度
5. **流派方程**：双流派组合触发协同效果，鼓励创造性搭配
6. **与现有系统无缝集成**：祝福与技能树、等级、挑战、成就都有交互
