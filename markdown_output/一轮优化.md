# 《股票大亨》一轮优化设计：资金系统 · 流派卡片 · 称号等级

> 本文档在 [UI.md](UI.md)（卡牌识破 AI 核心玩法）基础上，新增三大系统，把游戏从"一次性 7 日跑"升级为**有局外持久成长的肉鸽（Roguelite）**：
> 1. **资金系统**（三角洲式带入/带出 + 奇物商店）
> 2. **流派与卡片整合**（开局选流派 → 卡池加权）
> 3. **称号与等级系统**（资产驱动 + 流派精通）
>
> 参考：三角洲行动（撤离玩法）、模拟宇宙（祝福/流派/奇物，见 [模拟宇宙扩展设计.md](模拟宇宙扩展设计.md)）。

## 〇、先澄清一处规则矛盾

你写的撤离规则两个分支都写了"排名第一"，互相矛盾：

> "如果本轮收益为排名第一，则奇物销毁，资金带出，若排名第一则可带出资金和奇物"

我按**三角洲撤离逻辑**理解，并采用**前三名 = 撤离成功**（7 人里前 3 名）：

| 本局结果 | 资金 | 奇物 |
|---------|------|------|
| 🏆 **前三名**（撤离成功） | **带出**（当前资金回银行） | **保留**（可带进下一局复用） |
| 💀 **第 4~7 名**（撤离失败） | **带出**（当前资金仍回银行） | **销毁**（本局购买的奇物全损） |

即：**资金永远能带出**（但带出的是"交易后的当前资金"，可能比带入多也可能少 → 资金的风险来自交易本身）；**奇物是真正的高价值赌注**——挤进前三能囤货复用，掉出前三血本无归。

> 前三名保奇物让胜率从 ~14%（仅第一）提到 ~43%，奇物经济更健康、玩家更愿意买奇物冒险。若你本意是更硬核的"撤离失败连资金也亏损一部分"，见 [§8 假设](#八假设与待确认)，可作为难度选项。下文以上表为准。

## 一、三层结构总览

优化后游戏分三层，**局外持久、局内消耗**：

```
┌─ 银行层（持久 · 跨局）──────────────────────────────┐
│  • 银行总资产（meta 资金，驱动称号）                  │
│  • 已解锁称号 / 流派精通进度 / 已囤积的奇物仓库         │
└──────────────────────────────────────────────────┘
        ↑ 带出（资金±交易盈亏，奇物视撤离成败）
        │
┌─ 一局层（一轮 = 7 个交易日）─────────────────────────┐
│  • 带入资金（从银行选定额度作为本局本金）              │
│  • 选 1 个流派（影响本局卡池）                         │
│  • 局内可买奇物（整局生效）                           │
│  • 7 日后排名结算 → 撤离                              │
└──────────────────────────────────────────────────┘
        ↑ 每日循环
        │
┌─ 一日层（[UI.md](UI.md) 的核心循环）──────────────────┐
│  开盘新闻 → AI发言 → 抽卡(3选2) → 行动(5AP) → 骰子结算  │
└──────────────────────────────────────────────────┘
```

## 二、资金系统

### 2.1 银行账户（持久资金）

- 玩家有一个**银行总资产**，跨局保留，是 meta 进度的核心数字。
- 新号初始银行：`¥100,000`。
- 银行资产驱动**资产称号**（见 [§4.1](#41-资产称号阶梯)）。
- 银行破产保护：若银行 < 一局最低带入额，给予"救济金"重置到最低线（避免卡死），但记一次"破产"。

### 2.2 带入机制（本局本金 · 三角洲式 stake）

- 每局开始，玩家从银行**选择带入额度**作为本局本金。
- 带入区间：`[最低带入, 银行余额]`，最低带入默认 `¥50,000`；带入上限受**资产称号**提升（见 §4）。
- **带入越多 → 交易/买奇物的操作空间越大，但交易亏损也按当前资金放大 → 银行波动更大**。这就是 stake 的取舍：保守小带入稳，激进大带入博。
- 带入后，本局内的"现金"= 带入额，所有交易/购物都在此池子里进行。

### 2.3 局内资金用途

| 用途 | 说明 |
|------|------|
| 股票交易 | [UI.md](UI.md) 的快捷买卖（25/50/80% 买，30/50/100% 卖），消耗行动点 |
| 抽卡刷新 | 每日候选卡刷新消耗现金（递增 500→1500→5000，沿用模拟宇宙 §8.2） |
| **奇物商店** | 用现金购买奇物，获得整局生效的强力 buff（见 §2.4） |

### 2.4 奇物商店（Curio Shop）

- 入口：局内常驻"商店"按钮（或午间休市进入）。
- 奇物特点：**整局（7 日）持续生效**，区别于"祝福卡"（仅当日）。
- 每局奇物商店随机上架 3~4 件，可花现金购买；**每局最多持有 3 件奇物**（沿用模拟宇宙 §6.2）。
- **撤离成败决定奇物去留**（见 §2.5）：赢了带回银行仓库下次能复用，输了销毁。

### 2.5 结算与撤离（局末）

7 个交易日结束后，按**本局总资产**（现金 + 持仓市值）对玩家与 6 个 AI 排名，**前三名 = 撤离成功**：

```
┌──────────────────────────────────────────┐
│  🏁 第 7 日收盘 · 本局撤离结算              │
│  你的本局总资产：¥138,500（带入 ¥100,000） │
│  排名：2 / 7  🏆 撤离成功！（前三）         │
│                                           │
│  → 资金 ¥138,500 带回银行（+¥38,500）      │
│  → 奇物 [骰子灌铅][内幕通讯器] 收入仓库      │
│  → 流派精通【激进】+1（累计 4 次）          │
└──────────────────────────────────────────┘
```

- **前三名（撤离成功）**：资金带出 + 奇物保留进银行仓库（下局可携带）。
- **第 4~7 名（撤离失败）**：资金照常带出（= 当前总资产，含交易盈亏）；**本局所购奇物全部销毁**（持有"保险箱"则保 1 件）。
- 银行净变化 = 带出资金 − 带入资金（可正可负）。


## 三、流派、卡片与事件整合

### 3.1 卡池结构

卡牌分**常驻基础卡**与**候选卡**两类：

| 类别 | 来源 | 使用 | 时效 |
|------|------|------|------|
| **买入卡 / 卖出卡**（基础） | 常驻手牌（永远在） | 1 AP，玩家自填价格/数量（[§3.7](#37-买卖卡与限价成交机制玩家自填价格)） | 永久 |
| **信息卡** | 候选卡池（流派中立） | 行动阶段用，1 AP，目标 1 个 AI/新闻 | 用前持久保留 |
| **祝福卡** | 候选卡池（属于某流派） | 行动阶段激活，得当日 buff | 用前持久保留 |

- 每日仍"3 选 2"：抽 **3 张候选卡**，选 **2 张**进手牌（选牌不耗 AP）。
- **手牌不再每日清空**：选入的信息/祝福卡持续保留、跨日跨局，直到用掉（[§3.8](#38-持久手牌选牌跨日跨轮保留)），手牌有上限。
- **取舍**：行动点（5/日）才是真正的瓶颈——买卖、调查、激活祝福都抢这 5 点；卡可以囤，但一天打不出几张。

### 3.2 开局选流派 → 卡池加权

- **每局开始前，玩家选 1 个流派**（六选一）。
- 选定后，本局抽卡概率重新加权：

```
该流派的祝福卡：基础权重 × 2
其余流派的祝福卡：基础权重 × 0.5
信息卡（中立）：权重不变
```

- 效果：你会更频繁抽到本流派祝福，自然走向流派 build；但信息卡始终保底可抽，不会丢掉核心调查玩法。
- 持有奇物 `流派图腾🗿` 时，本流派祝福权重再 ×2（即 ×4）。

> 加权用"权重抽样"实现：每张卡一个 weight，归一化后按概率抽 3 张不重复。

### 3.3 六流派祝福卡（适配骰子/识破玩法）

> **两条贯穿全设计的原则（本次优化新增）：**
>
> **① 骰子是隐藏的后台结算引擎，绝不向玩家暴露原始骰子数/成功数。** 玩家只看到收盘后的**涨跌幅（%）**。所有卡牌效果必须用玩家语言描述——**"上涨概率/涨跌倾向评级/确定收益"**，而不是"+N 骰 / 揭示骰数"。下表中 `(机制:…)` 是给程序看的后台实现，不展示给玩家。
>
> **② 买卖额度改为玩家自由输入**（不再是 25/50/80% 固定按钮，见 [§3.6](#36-买卖改为自由额度对激进流的连锁修正)）。因此"提高仓位上限"类效果失效，激进流改用**杠杆（借钱买超过现金的仓位）**来体现。

每个流派给一组当日祝福卡（代表性，更多可从模拟宇宙 §2.2 扩展并重皮）：

#### 🛡️ 稳健防守流
| 卡 | 效果（当日） | 机制 |
|----|-------------|------|
| 止损护盾 | 今日任一只亏损持仓，收盘跌幅上限锁定 -3% | 收盘跌幅 < -3% 时按 -3% 计 |
| 安全垫 | 今日返还某一只亏损持仓 50% 的损失（≤¥500） | 取当日最大单笔亏损返还 |
| 分散下注 | 持有≥3 只股票时，今日所有亏损持仓跌幅减半 | 亏损方向涨跌幅 ×0.5 |

#### ⚔️ 激进进攻流
| 卡 | 效果（当日） | 机制 |
|----|-------------|------|
| 杠杆冲锋 | 今日可用资金 ×1.5（可借钱买入超过现金的仓位，收盘随仓位放大盈亏） | 现金购买力上限 ×1.5 |
| 翻倍下注 | 指定 1 只股，今日该股盈亏 ×1.5 | 该股涨跌幅 ×1.5（盈亏同放大） |
| 连胜狂热 | 今日连续 2 笔盈利后，下一笔盈亏 ×2 | 触发后单笔涨跌幅 ×2 |

#### 🔮 信息先知流
| 卡 | 效果（当日） |
|----|-------------|
| 免费情报 | 今日首张信息卡不耗行动点 |
| 深度透视 | 今日"查仓"额外揭示该 AI 的下注强度 |
| 新闻预读 | 今日开局直接得知新闻真假（≈白嫖一张"对照新闻"） |

#### 🏄 趋势跟随流
| 卡 | 效果（当日） | 机制 |
|----|-------------|------|
| 顺势加成 | 与多数 AI 同方向下注的股票，**上涨概率提升**（顺势更易赚） | 该股结算 +1 骰（玩家不可见，仅表现为更易涨） |
| 动量信号 | 今日显示 5 只股票的**动量评分**（↑↑/↑/→/↓/↓↓），辅助判断方向 | 动量是玩家面板指标，非骰子 |
| 快速止盈 | 今日卖出操作不消耗行动点 | — |

#### 🎲 事件驱动流
| 卡 | 效果（当日） |
|----|-------------|
| 混沌触发 | 今日额外触发 1 个随机事件 |
| 浑水摸鱼 | 今日所有交易成本（手续费）归零 |
| 重写头条 | 今日可重 roll 一次今日新闻事件 |

#### 🤖 量化算法流
| 卡 | 效果（当日） | 机制 |
|----|-------------|------|
| 胜率估算 | 今日下注前显示该股的**上涨概率评级**（★~★★★★★） | 由后台骰数换算成概率星级，不露骰子 |

### 3.5 流派回响（可选 · 局内成长）

- 本局内每激活该流派一张祝福卡，累计"流派能量"。
- 累计 3 / 6 张同流派祝福 → 解锁该流派**回响**（一个强力主动技，每日限用 1 次），效果沿用模拟宇宙 §5。
- 因开局选流派+卡池翻倍，一局内凑够同流派祝福是可达成的。
- **方程（双流派协同）本版不做**，留作后续（与"专精单流派"的设计方向有冲突，详见 §8）。

### 3.6 买卖改为自由额度，对激进流的连锁修正

买卖从"25/50/80% 固定按钮"改为**玩家自由输入金额/数量**（可保留几个快捷预设作为辅助）。连锁影响：

- **默认购买力上限 = 当前可用现金（100%）**。"提高仓位上限"这类效果不再成立。
- **激进流改用"杠杆"体现**：杠杆让你能买入**超过现金**的仓位（借钱），盈亏随之放大——这才是自由额度下激进的真正取舍。
  - 祝福「杠杆冲锋」：当日购买力 ×1.5
  - 奇物「杠杆契约」：本局购买力上限 ×2
  - 流派精通「嗜血狂徒」：选激进流时永久解锁 ×1.5 基础杠杆
- **杠杆风险**：用杠杆买入后若收盘亏损，按放大后的仓位计亏，可能亏掉超过本金的部分（触发强平/补缴），需在 UI 明确提示。
- 📌 **需同步改 [UI.md §4.2](UI.md)**：交易区把六个百分比按钮换成"金额输入框 + 可选快捷预设 + 杠杆开关"。

### 3.7 买卖卡与限价成交机制（玩家自填价格）

交易不再是点按钮，而是打出**买入卡 / 卖出卡**——两张**常驻基础卡**（永远在手牌坞，不占抽到的卡位），打出时弹出填单，玩家自填信息。

| 卡 | 玩家填写 | 消耗 |
|----|---------|------|
| 买入卡 🟢 | 目标股 + **出价 B** + 金额/数量 | 1 行动点 |
| 卖出卡 🔴 | 目标股 + **要价 A** + 数量 | 1 行动点 |

**限价成交模型**（沿用 TRADE：**出价越高越易买成，要价越低越易卖成**）。每只股票当日有玩家可见的市场基准价 `P0`。打出卡后按你的价格与 P0 的偏离算**成交概率**：

| 买入出价 B | 成交概率 | | 卖出要价 A | 成交概率 |
|-----------|---------|---|-----------|---------|
| B ≥ P0×1.02 | ~100% | | A ≤ P0×0.98 | ~100% |
| B = P0 | ~70% | | A = P0 | ~70% |
| B = P0×0.98 | ~40% | | A = P0×1.02 | ~40% |
| B ≤ P0×0.95 | ~10% | | A ≥ P0×1.05 | ~10% |

- **成交价**：买入按你的出价成交（出价高于市价时只按市价附近收，不白多付）；卖出按要价成交。
- **未成交**：行动点照常消耗，订单作废（是否退还行动点见 §8 待调）。这就是"出价"的赌——低价省钱但可能买不到、还白扔行动点。
- **AI 竞价压力（连接识破玩法）**：当日 AI 对某股的净买卖意图会**抬高/压低成交门槛**——AI 都抢着买的股，你得出更高价才买得到（且收盘更易涨）；都在抛的股，你要价得更低才卖得掉。
  - 机制：成交概率曲线的 `P0` 基准随"AI 净买入压力"上浮、"净卖出压力"下移。
  - 战术闭环：**先用信息卡查清 AI 意图 → 再决定出价**，是高手操作。把"调查"和"下单"真正串起来。
- **两层风险**：成交（买不买得到）→ 收盘骰子结算（买到后涨不涨）。执行风险 + 结果风险叠加。
- **与自由额度的关系**：[§3.6](#36-买卖改为自由额度对激进流的连锁修正) 的"自由金额"就填在买/卖卡里，杠杆决定金额上限。

### 3.8 持久手牌：选牌跨日、跨轮保留

把原"当日未使用手牌收盘清空"改为——**选入的卡持续保留，直到被用掉，不因换日或换局而清空**。

- 每日仍"3 选 2"补充新卡进手牌。
- **手牌上限封顶**（默认 6 张，可调）：满了必须先用掉/弃掉才能再选，防止无限囤积。
- **跨轮（跨局）保留**：一局结束，手牌里没用完的卡进入"随身牌库"，下一局开局带入。这正是"上一轮的选牌保留到下一轮"。
- **保留无条件**（不像奇物受前三限制），形成清晰对照：

| 资产 | 跨局保留条件 |
|------|-------------|
| 信息/祝福卡（手牌） | **无条件保留**（卡是你的"手艺/工具"） |
| 奇物 | 仅前三名保留（赌命的战利品） |
| 资金 | 永远带出（±交易盈亏） |

- 买入/卖出基础卡本就常驻，不在保留计数内。
- 📌 **需同步改 [UI.md](UI.md)**：底部手牌坞从"固定 2 张、收盘清空"改为"可持有至上限 N 张、跨日跨轮保留 + 2 张常驻买卖卡"。

### 3.9 事件系统：AI 结合股票随机生成

盘中随机事件改为**结合具体股票、由 AI（DeepSeek）生成叙事**，但**结算影响始终由本地规则锁定**（全局原则：大模型只写文案，不决定结果）。

生成管线：
1. **本地掷骰**：随机选 1 只股票 + 事件性质（利好/利空/中性）+ 真假 + 影响档位（隐藏结算数据）。
2. **喂上下文给 DeepSeek**：股票名/行业、方向提示、当前交易日、市场情绪。
3. **DeepSeek 产出**：一段事件叙事（"谁在哪做了什么"）+ 2~3 个选项文案。
4. **本地锁定选项结果**：每个选项的奖励/惩罚/对该股影响由规则定，DeepSeek 不参与。
5. **兜底**：DeepSeek 不可用 → 本地事件模板库（按股票占位符填充）。

示例：
> 本地：`{stock=东海化工, 利好, 真, +1档}`
> → DeepSeek 叙事："东海化工宣布与某车企签下 3D 耗材独家大单……"
> → 选项：重仓杀入 / 轻仓试探 / 按兵不动（结果本地锁定）

- 事件影响落到**该股当日结算**（真利好/利空/假，玩家不可见，仅表现为涨跌倾向——遵守 §3.3 原则①）。
- 与"今日新闻"（[UI.md §4.1](UI.md)）一致：玩家仍需自己推理"影响哪只、真还是假"，可用"对照新闻/查仓"等卡辅助。

### 4.1 资产称号阶梯（银行资产驱动）

银行**历史峰值资产**达到门槛即永久解锁对应称号；称号提供**永久 meta 加成**。玩家可佩戴已解锁的任一称号。

|----|------|------------|---------|

| 2 | 小有积蓄 | ¥200,000 | 带入上限 +¥50,000 |
| 3 | 操盘新贵 | ¥500,000 | 每局开局赠送 ¥5,000 启动金 |
| 4 | 资本玩家 | ¥1,000,000 | 奇物商店折扣 10% |

### 4.2 流派精通特殊称号（盈利次数驱动）

用某流派**撤离成功（前三名）**累计达标 → 解锁该流派专属称号 + 流派专属加成：

| 流派 | 3 次精通 | 7 次精通 | 15 次精通（宗师） | 宗师加成 |
|------|---------|---------|------------------|---------|
| 🛡️ 稳健 | 守财奴 | 铁壁 | **不动尊者** | 选稳健流时，**一轮免疫一次亏损**（完全免除某一次亏损结算） |
| ⚔️ 激进 | 莽夫 | 赌徒 | **嗜血狂徒** | 选激进流时，**永久解锁 ×1.5 基础杠杆**（购买力 ×1.5） |
| 🔮 信息 | 包打听 | 情报贩子 | **千里眼** | 选信息流时，每日免费查 1 个 AI 真实方向 |
| 🏄 趋势 | 跟风客 | 弄潮儿 | **浪人之王** | 选趋势流时，顺势股**上涨概率永久提升**（机制:顺势股结算 +1 骰，玩家不可见） |
| 🎲 事件 | 看热闹 | 搅局者 | **混沌之主** | 选事件流时，每日必触发 1 个有利事件 |
| 🤖 量化 | 调参侠 | 模型师 | **奇点** | 选量化流时，每日免费揭示 1 股的**涨跌倾向评级**（5 档标签，不露骰子） |

- 流派精通加成**仅在本局选了对应流派时生效**（鼓励专精）。
- 精通进度记在银行层，跨局累计。
- 计数口径：**撤离成功（前三名）才 +1**。掉出前三的局不计入精通。

### 4.2.1 称号体系成为主进度线

因为称号现在承载了"带入上限 / 行动点 / 抽卡数 / 奇物折扣 / 流派专精"等全部成长，它**取代旧 XP 等级成为玩家的核心 meta 进度线**。玩家的长期目标 = 把银行做大解锁高阶资产称号 + 把流派打精通。

### 4.3 称号加成生效规则

为避免加成无限叠：

1. **里程碑加成**（资产阶 1~4 的弱加成、流派精通 3/7 级）：解锁后**永久被动生效**。
2. **主称号加成**（资产阶 5~8 的强加成、流派宗师加成）：需**佩戴**，同时只能戴 **1 个资产主称号 + 1 个流派宗师称号**。
3. 佩戴在"局外准备界面"切换，进局后锁定。
